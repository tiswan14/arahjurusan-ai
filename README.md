# 🚀 ArahJurusan AI

Platform berbasis AI untuk membantu siswa menentukan jurusan SMK yang sesuai dengan minat, bakat, dan prospek karir masa depan.

---

## 🧠 Tentang Project

ArahJurusan AI adalah landing page modern yang dirancang untuk:

- Membantu siswa memilih jurusan secara objektif
- Memberikan rekomendasi berbasis AI
- Menampilkan prospek karir masa depan
- Memberikan pengalaman UI modern, responsif, dan clean

---

## 🛠 Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion
- Lucide Icons

---

## ⚙️ Getting Started

### 1️⃣ Install dependencies

```bash
npm install
```

### 2️⃣ Jalankan development server

```bash
npm run dev
```

Buka di browser:

```
http://localhost:3000
```
